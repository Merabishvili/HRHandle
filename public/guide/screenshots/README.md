# Guide screenshots

One folder per language — `en/`, `ka/`, `ru/` — with the same file names. A guide's
`<Screenshot name="…" />` loads the image from the folder of the language the article is
in. Pixel sizes are recorded in `content/guides/screenshots.json`.

The files are generated by `npm run guide:screenshots` (Playwright). Don't edit them by
hand — the next capture overwrites them.

```bash
npx playwright install chromium   # once
npm run guide:seed                # the EN / KA / RU demo companies on staging
npm run guide:serve               # local build on staging data, port 3123 — leave running
npm run guide:screenshots -- --topic post-a-vacancy --preview /tmp/guide-preview
```

Full instructions: `docs/5-environment/local.md` → "Capturing guide screenshots".
Flows (what each shot clicks and marks): `scripts/screenshot-config.ts`.
